# 동기화와 감사 (SYNC / AUDIT)

코드와 문서의 불일치를 찾는 두 가지 방식입니다. 기본은 빠른 `SYNC`(diff 기반), 사용자가 전체 점검을 원하면 `AUDIT`(전수 감사)입니다. 어느 쪽이든 결과는 SKILL.md의 진단 보고 형식으로 보고하고, 승인받은 항목만 수정합니다.

## SYNC — git diff 기반 (기본)

최근 변경이 어떤 문서를 낡게 만들었는지만 집중 검사합니다. 일상 워크플로우("기능 넣었으니 문서도 맞춰줘")에 적합합니다.

### 절차

1. **변경 범위 결정.** 사용자가 지정하지 않으면 우선순위: 작업 트리의 미커밋 변경 → 현재 브랜치가 기본 브랜치에서 갈라진 이후 커밋(`git diff main...HEAD`) → 최근 커밋 몇 개. 어떤 범위를 잡았는지 진단 보고에 명시합니다.
2. **변경 사실 추출.** diff에서 문서에 영향을 줄 수 있는 변경만 추립니다:
   - 공개 인터페이스: 함수/클래스 시그니처, CLI 옵션·명령, API 엔드포인트, 설정 키, 환경 변수
   - 사용자 절차: 설치·빌드·실행 방법, 스크립트 이름, 의존성 추가/제거
   - 구조: 파일/디렉터리 이동, 모듈 분리·통합
   - 내부 리팩터링(동작 불변)은 아키텍처 문서에 영향 없으면 건너뜁니다.
3. **영향 문서 탐색.** 추출한 각 사실에 대해 문서 쪽을 검색합니다 — 바뀐 식별자·옵션명·경로를 README와 docs/ 전체에서 grep. 옛 이름이 문서에 남아 있으면 불일치 확정, 새 기능이 문서 어디에도 없으면 누락 후보입니다.
4. **누락 분류.** 대상 문서가 다루겠다고 약속한 독자·범위·공개 인터페이스와 대조해 필수 누락, 선택적 보강, 비대상으로 나눕니다. 코드에 존재한다는 이유만으로 모든 신규 기능을 필수 누락으로 만들지 않습니다.
5. **진단 보고.** 불일치·필수 누락·선택적 보강을 근거(diff의 커밋/파일:라인)와 함께 구분해 보고합니다. 비대상은 보고하지 않습니다.

### 판단 기준

- **불일치 > 누락.** 틀린 문서(옛 옵션명, 사라진 명령)가 없는 문서보다 해롭습니다. 진단 표에서 불일치를 먼저, 누락을 뒤에 배치합니다.
- **필수 누락 > 선택적 보강.** 필수 누락은 독자가 작업을 완료하거나 중요한 공개 기능을 찾는 데 필요한 내용입니다. 선택적 보강은 별도 낮은 우선순위로 표시합니다.
- 새 기능의 문서화 여부는 프로젝트의 문서화 수준에 맞춥니다. README가 주요 옵션만 다루는 프로젝트라면 사소한 내부 옵션 누락은 항목에 넣지 않습니다.

## AUDIT — 전수 감사

문서 전체를 코드베이스와 대조하는 느린 전수 조사입니다. 주기적 점검이나 "문서 전체가 믿을 만한지 모르겠다"는 상황에 적합합니다. 시작 전에 대상 문서 목록과 예상 소요를 한 줄로 알리고 진행합니다.

### 절차

1. **문서 인벤토리.** README, docs/, 문서 사이트 콘텐츠, 각 패키지의 README 등 모든 문서를 나열합니다.
2. **문서별 사실 검증.** 각 문서에서 검증 가능한 주장(명령어, 옵션, 경로, 파일명, 버전, 동작 설명)을 추출해 코드와 대조합니다:
   - 명령어·스크립트: package manifest의 scripts, CLI 정의와 대조. 안전한 것은 실행해 확인.
   - 경로·파일명: 실제 존재 확인.
   - 옵션·설정 키: 소스의 정의와 이름·기본값 대조.
   - 코드 예제: import 경로와 API 시그니처가 현재 코드와 맞는지.
3. **죽은 문서 탐지.** 어떤 코드에도 대응하지 않는 문서(삭제된 기능 설명, 옛 아키텍처)와 깨진 내부 링크를 찾습니다.
4. **진단 보고.** 문서별로 묶어 보고하고, 심각도로 정렬합니다: ①따라 하면 실패하는 것(틀린 명령) ②오해를 만드는 것(낡은 설명) ③사소한 것(깨진 링크, 오타).

### 규모 조절

문서가 많으면(대략 10개 파일 이상) 한 번에 전부 하지 말고, 인벤토리를 먼저 보고해 우선순위를 합의한 뒤 중요한 것부터 감사합니다. 병렬 subagent를 쓸 수 있는 환경이면 문서별로 나눠 병렬 검증해도 됩니다 — 단, 진단 보고는 하나로 합쳐서 냅니다.
